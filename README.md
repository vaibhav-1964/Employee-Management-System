# Employee Management System

A Python-based Employee Management System designed to manage employee information, authentication, salary/payroll calculations, and department-wise reports.

## Features

- Employee registration
- Admin and employee login authentication
- Employee ID generation
- View employee details
- Update employee information
- Delete employee records
- Salary and bonus calculation
- Payroll calculation
- Department-wise salary reports
- JSON-based data storage

## Technologies Used

- Python
- JSON
- GitHub
